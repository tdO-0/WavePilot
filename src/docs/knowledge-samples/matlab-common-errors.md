# MATLAB 通信仿真实验常见错误

## 参数与数组

- 误码率网格因浮点累加缺失终点：建议按明确点数生成并在 Java 侧校验期望参数点。
- 矩阵维度不一致：在拼接结果前检查码长维度、样本维度与 Monte Carlo 维度。
- 随机种子未固定：会导致同一配置无法复现。

## 文件产物

- CSV 表头或列顺序变化会破坏下游验证。
- 输出 `NaN` 或 `Infinity` 时不能把任务标记为成功。
- 日志、摘要和明细使用不同参数时，报告结论不可追溯。

## 运行环境

- MATLAB 可执行文件不在允许的配置路径。
- 脚本依赖未声明或工作目录错误。
- 脚本从用户输入拼接 shell 命令，存在命令注入风险。

WavePilot Phase 3 仍使用 Mock Runner，没有执行 MATLAB。未来 Local MATLAB Runner 必须通过受控模板传参，设置超时与资源限制，并由 Java `ResultValidator` 对产物进行二次校验。
