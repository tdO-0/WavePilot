# Monte Carlo 参数选择指南

## 参数职责

- `sampleCount`：单次参数组合使用的样本数量。
- `monteCarloTimes`：对同一参数组合重复运行的次数。
- `randomSeed`：伪随机序列的起点，用于重现实验。

## 选择建议

学习和接口联调可先使用 10 至 50 个样本、5 至 20 次重复，以快速发现参数和产物问题。正式统计分析应根据目标置信区间增加样本量与重复次数，并记录资源消耗。

总工作量近似为：

`码长数量 × 误码率点数量 × sampleCount × monteCarloTimes`

当误码率步长过小或重复次数过高时，工作量会快速放大。WavePilot 的 Java 校验器会拒绝非法范围，并对高资源风险给出确定性警告；大模型不能绕过该校验。

## 可复现性

同一算法版本、同一 Spec 和同一随机种子应产生可比较结果。修改任何参数后应创建新任务，避免覆盖旧产物。随机种子缺失时，当前解析器默认使用 20，并在解析结果中明确披露该默认值。
